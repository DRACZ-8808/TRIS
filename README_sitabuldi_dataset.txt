Sitabuldi traffic-risk prototype dataset

This is simulated demo data for hackathon prototyping, not official Nagpur Police data. It models six representative junctions, 2025 dates, and eight daily observation times.

Use risk_level as a dashboard label and risk_score for heatmap intensity. Features include congestion, speed, violations, accidents, weather proxy, crowding, events and historical risk. Replace simulated values with validated data before operational use.

Suggested Kaggle sources: Indian Traffic Violation Dataset (Kaggle) and Indian Road Accident Dataset (Kaggle). These may require cleaning and generally will not contain Sitabuldi-specific junction IDs, so map locations manually or retain them as separate contextual features.
